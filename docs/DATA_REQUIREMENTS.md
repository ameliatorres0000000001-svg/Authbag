# Data each brand × model × era needs

Readiness levels (computed live at `/coverage`, thresholds in Settings):

- **L0** no approved era → add era (years + identifier type: date code / RFID chip / serial / none).
- **L1** checklist only → capture checklist exists, no usable rules.
- **L2** ≥3 approved rules for that scope (source tier 1–3 preferred).
- **L3** retrieval ready: ≥5 approved *authentic* reference photos per era (own / consented / licensed; label basis receipt, boutique, provider certificate or expert consensus).
- **L4** fine-tune ready: ≥30 authentic and ≥10 counterfeit approved per era.

Per model × era collect: date-code/chip format + factory codes; hardware (zipper pull, stamp font/spacing, rivets, lock); stitching (count per cm, angle); canvas/pattern alignment; lining; hologram/label where the brand has one; macro photos of each.

Three data layers: A official-site text/specs only (no photos copied); B partner photos with written permission; C your own captures with customer consent. Record provenance on every asset. Never train on scraped or provider-owned images.

Louis Vuitton priority models (stubs seeded): Speedy Bandoulière 25, Keepall Bandoulière, Multi Pochette Accessoires, Palm Springs Mini, Avenue Sling Bag. Seeded rules are **draft** tier-4 hints from comparison photos; none counts until two people approve.
